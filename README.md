HAVEN PROPERTIES - ready-to-upload website
1. In cPanel, open File Manager, then public_html.
2. Upload index.html and .htaccess (or upload this zip and Extract it there).
3. Open your domain. Done. No database, no install.
To change your WhatsApp number: open index.html, find WHATSAPP_NUMBER near the bottom, edit it, save.
All listings are sample data. Edit the text in index.html, or use the Laravel version for easy listing management.
